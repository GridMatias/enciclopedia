#   python -c "import hashlib,sys;print(hashlib.sha256(sys.argv[1].strip().encode()).hexdigest())" "<the exact matched string>"
# Or read it off the linter message: every finding prints `sha256 <first 12>`.
# Anything shorter than 64 hex characters on a line is ignored.
#
# The alternative, for a one-off, is an inline marker on the line above:
#   <!-- enc:allow-secret documented example, not a live key -->
#   <!-- enc:allow-pii   contact published on purpose -->
#   <!-- enc:allow-injection  documenting the attack, not obeying it -->
#
